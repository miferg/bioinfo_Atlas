Filtrar secuencias con DARN¶

En windows

  • Crear una carpeta dentro de "C:" llamada "shared" y dentro de ella, otra llamada "atlas_coi"
  • Mover el archivo coiner.fna a la carpeta "atlas_coi"
  • Lanzar Docker
  • Bajar la imagen de darn desde la app buscando "hariszaf/darn"
  • Cerrar app
  • Abrir la línea de comandos: teclear inicio, escribir "cmd" y dar Enter
  • Lanzar el contenedor y montar la carpeta "atlas_coi": docker run --rm -it -v C:\shared\atlas_coi:/mnt hariszaf/darn
  • Ejecutar darn: ./darn.sh -s /mnt/coiner.fna -t 4
  • Salir del contenedor: exit
  • Revisar Krona
  • Cerrar la terminal
  • Cerrar Docker
  • "Subir" el archivo "darn_coin_eukaryota_assignments.fasta" de la carpeta "final_outcome" al directorio dia5 en jupyter

# crear función
def extract_taxa_from_sintax(sintax, crank, crankid):
    ctax_l = []
    for ci,crow in sintax.iterrows():
        cpath = crow['filt_path']
        if crankid+':' in cpath:
            ctax = cpath.split(crankid+':')[1]
            ctax = ctax.split(',')[0]
        else:
            ctax = np.nan
        ctax_l.append(ctax)
        
    return ctax_l

# crear función
def add_taxa_from_sintax(crank, prank, fulltab, sintax):
    ctax_d = {crow['id']:crow[crank] for ci,crow in sintax.iterrows()}
    fulltab[crank] = [ctax_d[ci].split('_')[0] if str(ctax_d[ci]) != 'nan'
                      else fulltab[prank][ci]
                      for ci in fulltab.index]
